# Auto-Mods fuer 7 Days to Die

Dieses Repository enthaelt ausschliesslich fertige Windows-Releases der Auto-Mods von Bloody:

- AutoCore
- AutoStash
- AutoCraft
- AutoPower
- AutoCams
- AutoStations

## Installation fuer Spieler

1. Unter **Releases** die Datei `AutoMods-Installer.exe` herunterladen.
2. 7 Days to Die vollstaendig beenden.
3. Die EXE starten und den erkannten Spielordner bestaetigen.
4. Das Spiel anschliessend ohne Easy Anti-Cheat starten.

Der Installer findet normale und zusaetzliche Steam-Bibliotheken automatisch, laedt das aktuelle Mod-Paket und
prueft dessen SHA-256-Pruefsumme vor der Installation. Vorhandene Auto-Mods werden gesichert. Der Vanilla-Mod
`0_TFP_Harmony` und fremde Mods bleiben unangetastet.

Wenn `0_TFP_Harmony` fehlt, in Steam die installierten Spieldateien auf Fehler ueberpruefen.

## Release-Dateien

- `AutoMods-Installer.exe` – eigenstaendiger Windows-x64-Installer
- `AutoMods-Paket.zip` – alle sechs fertigen Mod-Ordner
- `AutoMods-Paket.sha256` – SHA-256-Pruefsumme des ZIP-Pakets

Der Quellcode und die Entwicklungsdaten werden nicht in diesem oeffentlichen Download-Repository verwaltet.
